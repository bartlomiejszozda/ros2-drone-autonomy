Start

What one launch starts

ros2 launch collider collider.launch.py starts each node as its own process. Steering starts disabled, starter waits for a goal and safety only acts on a violation, so launching sends nothing to the vehicle. Switch parts off with these arguments:

ArgumentDefaultStarts / changes
with_simfalseGazebo, ArduPilot SITL, micro_ros_agent, MAVProxy, ros_gz_bridge (via iris_runway.launch.py). Add use_gz_sim_gui:=False rviz:=False to run them headless.
backendcmd_velSteering output: cmd_vel (GUIDED, DDS) or rc (LOITER, MAVLink). Also sets the mode mission switches to.
use_sim_timeTrueAll nodes follow /clock. Set False only when no simulator runs.
safetytruesafety_node. Mission refuses to start without it (require_safety).
startertruestarter_node
steeringtruesteering_node
missiontruemission_node
assistanttrueassistant_node, which needs OPENROUTER_API_KEY in the environment
car_detectortruecar_detector_node, which needs ultralytics and /opt/models/yolo11n-visdrone.pt
params_fileconfig/collider.yamlParameters for every node
(none)tracker_node and target_motion_node always start.

To run one node alone: ros2 run collider <name>_node. ros2 run collider benchmark_yolo is an offline YOLO speed test and joins no graph.

Call

Entry points you can call

These are the ▶ tabs in the diagram. Mission is the normal way to fly; the others let you drive one step at a time.

Fly a whole missionmission → starter → steering → LAND, RTL or hover
ros2 action send_goal /mission/run collider_interfaces/action/Mission \
  '{altitude_m: 5.0, duration_sec: 30.0, end_action: land}' --feedback
Launch the targetpushes the sphere up in the runway world
src/collider/scripts/launch_target
Cancel the missionCtrl+C on send_goal does not cancel it
ros2 service call /mission/run/_action/cancel_goal action_msgs/srv/CancelGoal '{}'
Take off onlystarter; stays hovering in GUIDED
ros2 action send_goal /starter/takeoff collider_interfaces/action/Takeoff \
  '{altitude_m: 5.0, timeout_sec: 60.0}' --feedback
Steering on or offfor rc, switch to LOITER first
ros2 service call /steering/enable std_srvs/srv/SetBool '{data: true}'
Safety buttonsbrake, land, rtl; reset clears a trip
ros2 service call /safety/brake std_srvs/srv/Trigger
ros2 service call /safety/reset std_srvs/srv/Trigger
Ask about the camera imagescripts/ask sends a /collider/ask goal
ask where is the red car, give its centre in pixels
ask_new what do you see
